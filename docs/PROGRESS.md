# 项目进度与演进路线

当前版本：**0.3.3**（协议：`MIT`，主仓库：<https://github.com/suluoMISS/liuguang>）。

## 1. 当前状态（0.3.3）

- **零门槛桌面首启与 GUI 服务控制**：桌面首次启动自动初始化默认配置与壁纸库目录，GUI 内置 `systemd --user` 启停/自启/初始化面板与一键处理横幅，并支持热加载手工补写的 `[library]` 配置；

- **核心引擎与双形态运行**：一套 Rust 代码支持 Wayland 桌面壁纸层（`user` 人格）与无头 DRM/KMS 展示屏（`system` 人格），两者安装策略与权限严格隔离；
- **零拷贝解码与色彩修正**：完成 `liuguang-vaapi`（FFmpeg VA-API + libva 导出）及合成器兼容用 GPU NV12→RGB 着色器，支持无闪烁实时调节亮度与画面适配；
- **五重自动让路与内存控制**：覆盖全屏、游戏进程、显存阈值、电池供电与熄屏暂停，并支持长暂停自动卸载管线、稳态释放闲置 `wl_shm` 内存池与缩略图内存压缩；
- **曜晶流光 GUI 与对等 TUI**：
  - `liuguang-gui`（GTK4 + libadwaita）：4/6 列无间隙画报墙排版、侧栏检查器与实时滑杆调节、播放列表、多输出管理、设置与关于弹窗；
  - `liuguangctl tui`（Ratatui）：全面对齐 GUI 的曜晶调色板、顶栏实时遥测与暂停胶囊、媒体兼容性与正在使用状态、亮度及重置快捷键；
- **开箱即用安装与权限体系**：`scripts/install.sh` 支持环境体检、显式权限申请（`sudo` / `pkexec`）、`CacheDirectory=liuguang` 自动授权、`video/render/liuguang-ctl` 组管理及 Arch/RPM 打包配置。

---

## 2. 后续计划

1. **自动匹配高刷上限**：`video_fps_limit` 默认跟随显示器刷新率动态调整上限，减少手动修改配置；
2. **冷启动异步建管线**：将首次建解码管线的等待移出主事件循环，进一步缩短首帧出现前的主线程占用；
3. **10bit HEVC / AV1 硬解直通扩展**：在支持的 GPU 驱动与合成器上直接导出 P010 DMA-BUF，减少高色深视频转码需求；
4. **更多桌面环境生态适配**：探索针对非 wlroots 合成器的扩展/插件协议支持与更多发行版软件源打包。
