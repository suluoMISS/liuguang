# 远程终端控制台（`liuguangctl tui`）

`liuguang-tui` 为 SSH 运维、无桌面展示屏服务器或键盘流桌面用户提供终端控制界面，与 GTK4 图形界面采用同一套「曜晶流光（Obsidian Crystal）」暗色设计语言与核心功能对齐。

## 1. 启动方式

```bash
# 控制桌面用户会话
liuguangctl tui

# 控制无桌面系统服务（经 SSH 登录终端建议加 -t）
ssh -t user@host liuguangctl --persona system tui
```

> **安全边界**：TUI 纯属瘦客户端，只通过 Unix Socket IPC 与守护进程通信，不打开 `/dev/dri`，不扫描本地文件系统；按 `Q` 或 `Ctrl+C` 退出终端后，守护进程与壁纸画面不受任何影响。

---

## 2. 视觉与功能特性

- **统一曜晶调色板**：采用 `#0b0d14` / `#0e111a` 墨玉底色、`#9c88ff` 流光紫焦点高亮、`#72e6aa` 翡翠绿在线/正在使用标签与 `#f5c26b` 琥珀金自动让路警示。
- **四档终端自适应**：根据终端宽高自动在「宽终端三栏 + 双行顶底栏」「中等终端两栏 + 顶部 Tab」「窄终端单栏子页」「极小终端紧凑状态提示」间无缝切换。
- **顶栏实时遥测**：即时显示整数 FPS、CPU%、常驻内存，以及当前激活的暂停原因胶囊（如 `⏸ 电池省电`、`⏸ 游戏让路`、`⏸ 全屏让路`、`⏸ 显存让路`）。
- **七大功能页面（按 `1`–`7` 直达）**：
  1. `1 总览`：全局播放状态、解码器、暂停原因、逐通道实时摘要与性能遥测；
  2. `2 媒体库`：服务端分页、实时筛选（全部/图片/视频）、排序、250ms 防抖搜索、序号/正在使用圆点/帧率角标、右侧检查器（含 `● 正在使用`、`CompatState` 兼容性标签、编码规格、完整路径自动换行）以及来源管理弹窗；
  3. `3 播放列表`：顶部三态播放模式选择器（←/→ 即时切换单视频循环/顺序循环/随机播放）、新增/重命名/编辑/调整顺序；
  4. `4 显示器`：多屏输出列表与右侧**实时适配面板** —— 支持 `C/V` 切适配模式（`cover/contain/stretch/center`）、`+/-` 缩放、`h/l/K/J` 偏移、`X` 旋转、`b/B` **画面亮度（10%–100% + 等宽进度条）**、`0` **一键重置适配与亮度**，并严格分离 `A`（运行时生效）与 `S`（写入配置）；
  5. `5 转场`：切换效果（`fade`/`slide`/`wipe`/`circle`）、缓动曲线与持续时间；
  6. `6 系统`：整数 FPS、CPU、内存、线程、预读缓存统计、DRM master/原子提交对账计数、真实 Socket 与配置路径以及 `e` 断线重连；
  7. `7 静态壁纸`：独立设置/清除静态壁纸覆盖层。

---

## 3. 核心键位

| 键位 | 作用 |
|---|---|
| `1` – `7` | 切换七个功能页 |
| `Tab` / `Shift+Tab` | 切换焦点区域；小终端下 `←`/`→` 切换子页 |
| `?` | 打开上下文感知的完整按键帮助弹窗 |
| `Space` / `p` / `N` | 暂停/恢复 · 下一张 |
| `W` / `T` / `I` / `S` | 媒体库：应用选中壁纸 · 切换输出目标 · 手输绝对路径 · 来源管理 |
| `b` / `B` / `0` | 显示器页：亮度 `∓5%` · 重置全部适配与亮度 |
| `A` / `S` | 立即应用（运行时） / 持久保存（原子写回配置文件） |
| `Q` / `Ctrl+C` | 退出 TUI（不影响正在运行的守护进程） |
